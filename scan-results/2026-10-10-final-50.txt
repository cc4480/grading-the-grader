# The list was curated on 2026-10-09 and is reused unchanged so SecScan and another scanner can be compared on the same
# sites; only this header differs from the file it was copied from.
#
# Selection rules:
#   1. HELD OUT. No host appears in any earlier sweep (the 30-site corpus, the
#      20 guard targets, companies-50, tech-14, tls-mail-20) or in live-scan's own
#      5 defaults, www. ignored. The earlier sets were used to tune the false-positive
#      rules, so rescanning them mostly retests what is already fixed. This
#      list measures whether those rules generalise.
#   2. Large, well-resourced public sites. A passive scan is ~100-150 requests per
#      site (74 sensitive-path probes, a 10-page crawl, TLS, DNS).
#   3. No government, banking/payments, healthcare or critical-infrastructure
#      sites, and no small or personal sites.
#   4. Spread across stack and posture: strict-CSP framework sites, minimal
#      static sites, WordPress, big media, SaaS marketing, cloud/security vendors.
#
# Run (no arguments = the 5 defaults, so always pass the list; DATABASE_URL only has to be set):
#   cd artifacts/api-server
