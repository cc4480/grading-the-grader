Why the Cloudflare block matters

Search and answer crawlers (OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot, Googlebot, Bingbot) are let through, so citation in ChatGPT search, Claude search and Perplexity is not blocked by this. The blocked bots are the training crawlers. The audit scored AEO/GEO without testing any of this.

How to fix SEO Scan Pro

  1. Verify every suggestion against the crawled page before emitting it, and skip items that are already present (applicationCategory, operatingSystem, offers and totalTime were all there).
  2. Never suggest aggregateRating or Review markup unless genuine, visible reviews exist on the page.
  3. Never use an example price the site does not charge; read prices from the page (the audit suggested 99 for a $29 product).
  4. Stop recommending Rich Results Test validation for FAQ and HowTo. Say FAQPage is still valid markup but earns no rich result.
  5. Measure raw-HTML content and rendered content separately and report the gap. AI retrieval crawlers are commonly reported not to run JavaScript; say "commonly reported", not "tested per bot".
  6. Test crawler access by user agent (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, Claude-User, PerplexityBot, Perplexity-User, Googlebot, Bingbot, Applebot, CCBot, Bytespider) and report any 403 or block, and any conflict with robots.txt.
  7. Flag structured data that describes content which is not visible on the page (HowTo steps, FAQ answers).
  8. Do not present LLM-written scores as measurements. Label them model estimates, or compute deterministic scores.
  9. Count real <a href> links in both the raw and the rendered HTML; button-based navigation is invisible to crawlers.
